# 🛒 Retail Sales Analysis and Business Insights Using Python

## 📌 Project Overview

This project analyzes retail sales transaction data using Python to identify sales trends, product performance, category performance, store performance, and payment-method patterns.

The project demonstrates how data analysis and visualization can be used to convert retail transaction data into meaningful business insights.

> **Note:** The dataset used in this project is simulated for educational and portfolio purposes. It does not represent real customer transactions.

---

## 🎯 Objectives

- Analyze retail transaction data
- Clean and validate the dataset
- Calculate important retail KPIs
- Analyze monthly sales trends
- Identify high-performing products
- Compare product categories
- Compare store performance
- Analyze payment methods
- Create data visualizations
- Generate business insights

---

## 🧰 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Google Colab / Jupyter Notebook

---

## 📊 Dataset

The dataset contains **1,000 simulated retail transactions** from 2025.

### Dataset Columns

| Column | Description |
|---|---|
| Order_ID | Unique order identification |
| Date | Transaction date |
| Product | Product purchased |
| Category | Product category |
| Store | Store location |
| Quantity | Number of products purchased |
| Unit_Price | Price of one product |
| Total_Sales | Total transaction value |
| Payment_Method | Payment method |
| Month | Month of transaction |

---

## 🔍 Data Analysis

The project performs the following analysis:

### 1. Data Cleaning
- Checked for missing values
- Checked for duplicate records
- Verified data types

### 2. Retail KPIs
- Total Revenue
- Total Orders
- Total Quantity Sold
- Average Order Value

### 3. Sales Analysis
- Monthly sales
- Product-wise sales
- Category-wise sales
- Store-wise sales
- Payment method analysis
- Store and category comparison

| Highest Sales Month | December |
| Lowest Sales Month | March |

---

## 💡 Business Insights

- **Electronics** generated the highest revenue among the product categories.
- **Trichy** recorded the highest revenue among the stores in the simulated dataset.
- **Laptop** was the highest-revenue individual product.
- **December** recorded the highest monthly sales.
- **March** recorded the lowest monthly sales.
- The average transaction value was approximately **₹89,453**.
